## What Are Vaultbreakers Keys?

In Vaultbreakers, a key is a consumable item that opens something you can't otherwise reach: a sealed vault door, a reinforced loot cache, a shortcut, or an extraction route that lets you leave with your haul. Keys are the bottleneck between finding loot and keeping it, which is why so many runs end with a full bag and a locked chest.

There are two broad families, and confusing them is the fastest way to lose value. **Run keys** are carried during a single run and open doors, caches, and shortcuts inside that run only. **Stash keys** persist between runs and unlock permanent vaults, progression gates, and content that stays available across sessions.

Exact names, icons, and drop tables shift between builds and playtests, so treat the categories in this guide as a framework rather than a fixed list. The underlying logic — spend scarce Vaultbreakers keys on the highest-value doors, and never gamble a permanent key on a temporary run — holds true no matter which patch you're playing on.

| Key family | Where it lives | What it typically opens | On death or wipe |
| --- | --- | --- | --- |
| Run key | Run inventory | Doors, caches, and shortcuts inside the current run | Usually lost |
| Stash key | Persistent stash | Long-term vaults and progression gates | Kept |
| Event key | Limited-time inventory | Seasonal vaults and rotating bonus rooms | Usually expires |
| Vendor key | Stash or trade window | Trader stock, contracts, and player deals | Kept |

The practical takeaway: before you commit to a fight, know whether the key in your bag is a run key you can afford to burn or a stash key you'll regret losing.

## Where Do Vaultbreakers Keys Come From?

Keys don't drop from a single source, and players who only farm one activity tend to run dry. The table below breaks down the sources most commonly reported by the community, roughly ordered by how much value you get per hour of effort.

| Source | Reliability | Notes |
| --- | --- | --- |
| Named bosses and mini-bosses | High | Widely reported as the most consistent source; encounter reward pools often include a key or key material |
| Elite and rare enemies | Medium | Random, but worth killing while you're already clearing a zone |
| Locked rooms inside a run | Medium | Sometimes a key opens a room containing another key — chain-opening is a real strategy |
| Vendors and traders | High but costly | Reliable, though you're spending currency or materials you could use elsewhere |
| Contracts and daily objectives | Medium–high | Slow, steady, low-risk; ideal for players who don't want to gamble on RNG |
| Limited-time events | High while active | Event keys are usually generous but vanish when the event window closes |
| Other players | Variable | Trading and extraction economies let you convert spare loot into keys |

One pattern shows up again and again in player experience reports: clear the high-tier enemies in a zone *before* you loot the low-tier containers. Key drops tend to come from the same reward pools as your best gear, so the fight you were tempted to skip is often the one holding the key.

If you want to confirm what's currently dropping and where, the [official Steam store page](https://store.steampowered.com/) and its news feed are the fastest places to check patch notes, since key behavior is one of the systems most likely to be tuned between builds.

## The Main Key Archetypes and What They Unlock

Most vault-looting games — Vaultbreakers included — sort keys into a handful of recognizable archetypes based on what they open and how scarce they are. Names differ between builds, but the function rarely does.

| Archetype | Typically unlocks | Spend priority | Why it matters |
| --- | --- | --- | --- |
| Common key | Basic caches and minor side rooms | Low | Cheap to replace; don't hoard them |
| Vault key | The main vault room or high-tier cache | High | Usually the best value per key in a run |
| Boss key | A bonus chamber after a boss encounter | High | Frequently gates the run's best loot |
| Escape key | A shortcut or alternate extraction point | Situational | Priceless when you're overloaded and being chased |
| Event key | Seasonal vaults and rotating bonus rooms | High while active | Often expires, so an unused key is a wasted key |

A simple rule that works in almost every build: spend common keys freely, save vault and boss keys for runs where you're confident you can survive the trip out, and treat escape keys as insurance rather than as loot.

### Do You Need Every Key You Find?

No — and trying to collect them all is a trap. Inventory space is limited, and carrying three keys you'll never use means leaving behind gear you would have used. Pick the two or three archetypes that match your current goal, and sell, trade, or dismantle the rest.

## How to Use Vaultbreakers Keys Without Wasting Them

Good key management is less about reflexes and more about decisions made before the run starts.

- **Identify the door before you spend the key.** A key spent on a room that turns out to hold common materials is a key you can't spend on the vault two rooms later.
- **Never bring a stash key into a risky run.** If a key survives death, it belongs in your stash — not in the bag you're about to carry into a boss fight.
- **Stack your key runs.** If you have several keys of the same type, run them back to back so a single successful extraction covers multiple doors.
- **Plan the exit first.** An escape key is worth more than a loot key when you're carrying a full haul, because the loot you lose on death is worth more than the loot you didn't pick up.
- **Track expirations.** Event keys that disappear at the end of a season are functionally worthless the moment the window closes.

| Common mistake | What it costs you | Better habit |
| --- | --- | --- |
| Hoarding common keys "for later" | Inventory space and tempo | Use them on the first decent cache you find |
| Using a permanent key on a random run | Permanent progression | Keep stash keys out of run inventories |
| Opening every door you can | Keys you needed for the main vault | Prioritize by loot tier, not by proximity |
| Ignoring the exit until it's too late | The entire haul | Scout an extraction route before you loot |
| Buying keys from vendors on impulse | Currency you needed for gear | Buy only when the key's target is confirmed |

## Farming Vaultbreakers Keys Efficiently

Efficiency here means repeatable routines, not lucky drops. The routines below are the ones community reports describe as the most sustainable ways to keep a healthy stock of keys without grinding yourself into boredom.

| Routine | What to do | Effort | Payoff |
| --- | --- | --- | --- |
| Boss rotation | Run the encounters with the most reliable key drops back to back | Medium | High |
| Zone sweep | Clear elites and locked rooms before opening containers | Medium | Medium–high |
| Contract stack | Take daily objectives that reward keys or key materials | Low | Steady |
| Vendor check | Refresh trader stock at the start of each session | Low | Reliable |
| Event window | Play limited-time modes while event keys are live | Low–medium | High, but time-limited |

Two habits separate players with overflowing key stashes from players who are always one door short. First, they finish what they start — a zone half-cleared is a zone that paid out half its keys. Second, they never leave a session with event keys unused, because those are the only keys that depreciate to zero.

If your schedule is tight, the contract stack plus a vendor check takes very little time and keeps you supplied well enough to attempt a vault run whenever you have a free hour.

### A Quick Prioritization Checklist

1. Which keys expire soonest? Use those first.
2. Which keys are permanent? Keep them out of risky runs.
3. Which door in this run has the highest loot tier? That's your first key.
4. Do you have a safe way out? If not, an escape key outranks everything.

## FAQ

**Are Vaultbreakers keys permanent once you find them?**
It depends on the type. Run keys are typically consumed within the run they're used in and are lost if you die before spending them. Stash keys persist between sessions and are the ones worth protecting. Community reports suggest that if a key survives a wipe, you should treat it as a permanent asset and stop carrying it into dangerous runs.

**What's the fastest way to farm Vaultbreakers keys?**
The most efficient approach reported by players is a boss rotation combined with clearing elites in each zone before looting containers. Vendors and daily contracts fill the gaps when you don't have time for a full run, and limited-time events are usually the most generous source while they're active.

**Can you trade keys with other players?**
Trading depends on the build and mode you're playing. Where trading exists, it's a useful way to convert spare keys into the gear or materials you actually need. Check the current patch notes before assuming a key is tradable, since restrictions on consumables change fairly often.

**Should I use a key as soon as I find it?**
For common keys, yes — hoarding them costs inventory space and gains nothing. For vault and boss keys, no. Wait until you have a run where you're confident about surviving the extraction, because the value of a key is only realized if you walk out with what's behind the door.

The short version: Vaultbreakers keys are a resource like any other, and the players who get the most out of them aren't the ones who find the most — they're the ones who spend them at the right moment.
